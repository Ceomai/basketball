# Yayın öncesi kontrol: Google Play ve App Store

Tarih: 6 Kasım 2026 · Dal: `rel-a`. Bu belge mağazaya çıkmadan önce her şeyin tek yerden kontrol edilmesi için.
Üç bölüm var: **Hazır** (kodda yapıldı), **Senin yapman gereken** (hesap, para ya da karar gerektirir), **Risk** (bilerek bırakılan ya da doğrulanması gereken konular).

Hızlı kontrol: `npm run test:unit` (marka testi dahil) ve yayın kapısı `ADMOB_APP_ID=... VITE_ADMOB_REWARDED_ANDROID=... VITE_ADMOB_INTERSTITIAL_ANDROID=... npm run build && npm run release:check`.

## Senin yapman gerekenler (sırayla)

1. **E-posta:** `public/privacy.html` ve `public/delete-data.html` içindeki `[iletişim e-postası]` ve `[contact email]` (toplam 4 yer). Kalıcı, okunan bir adres olmalı.
2. **Karar:** kumar bölümleri (yukarıdaki tablo) ve uygulama kimliği.
3. **AdMob:** hesap, Android uygulaması, Ödüllü + Geçiş birimleri, GDPR mesajı, ödeme bilgileri. Uygulama Play'de yayınlanınca AdMob'da mağazaya bağla.
4. **app-ads.txt:** AdMob, Play sayfasındaki geliştirici web sitesinin **kök** adresinde `app-ads.txt` ister. `ceomai.github.io/basketball/` alt klasör olduğu için yetmez; kendi alan adın ya da `ceomai.github.io` kullanıcı sitesi deposunun köküne AdMob'un verdiği satırı koy. Yoksa reklam geliri kısıtlanabilir.
5. **İmza anahtarı + GitHub Secrets** (yukarıdaki 7 secret).
6. **Play Console:** geliştirici hesabı ve kimlik doğrulama; uygulama oluştur; Uygulama içeriği (gizlilik, reklam, reklam kimliği, hedef kitle 13+, veri güvenliği, IARC, hesap silme gerekirse); `adfree` ürünü.
7. **Kapalı test şartı:** 2023 sonrası açılan kişisel geliştirici hesaplarında üretime çıkmadan önce **en az 12 testçi, 14 gün kesintisiz** kapalı test zorunlu. İç test kanalı bu şartı saymaz; Kapalı test kanalı kullan.
8. **Ekran görüntüleri:** `npm run build:single && npm run screenshots` (kurgusal adlarla), Play'e TR ve EN.
9. **iOS:** `docs/IOS.md`.
10. İsteğe bağlı: Sentry DSN, Firebase Analytics, bulut kayıt (her biri gizlilik politikası ve veri güvenliği formunu değiştirir).

## Riskler ve notlar

- **Gradle derlemesi doğrulanmadı.** API 36 + AGP 8.9.1 + Capacitor 7 birleşimi yerelde derlenemedi (Android SDK yok). İlk CI çalıştırması başarısızsa hata günlüğüyle Capacitor 8'e geçiş en temiz yol.
- **Android 16 büyük ekran:** API 36 hedefleyen uygulamalarda tabletlerde (en kısa kenar ≥ 600 dp) `screenOrientation="portrait"` yok sayılır. Arayüz en fazla 560 px genişlikte ortalanıyor; yatay tablette çalışır ama boş kenarlar olur.
- **Google Fonts:** yazı tipleri `fonts.googleapis.com`'dan yükleniyor (IP adresi Google'a ulaşır; politikada yazıyor). İnternetsiz açılışta sistem yazı tipine düşer. İstenirse yazı tipleri pakete gömülebilir.
- **Test APK'sı herkese açık:** `apk-latest` sürümündeki hata ayıklama APK'sı Play sürümüyle aynı kimliği taşır ama farklı imzalıdır; testçiler Play sürümünü kurmadan önce onu kaldırmalı.
- **Mağaza metni:** "Oynamak için internet gerekmez (reklamlar için bağlantı gerekir)". Bulut yedek vaadi metinden çıkarıldı (özellik henüz açık değil).
- **Eski oyuncu kayıtları:** gerçek adlı haber/geçmiş metinleri açılışta çevrilir; semt ile aynı adlı kulüplerin (Beşiktaş, Karşıyaka, Göztepe...) eski serbest metinleri semt adı olarak kalır (takım adları ise anahtardan kurulduğu için doğru).
